# Flujos

## Reserva
Huésped -> Disponibilidad -> Habitación -> Reserva.

## Check-in
Reserva -> Verificación -> Resumen -> Cobro opcional -> Check-in -> Ocupada.

## Check-out
Ocupada -> Cobro de saldo -> Reserva finalizada -> Habitación en limpieza.

## Limpieza
Check-out -> Pendiente -> En limpieza -> Lista -> Disponible.

Los pagos se originan en CHECK_IN, CHECK_OUT o MANUAL y se guardan en el mismo store.
